### Вывод по развёртыванию
Docker есть → используем **docker compose** для нашего стека (db + api + web), порты только на `127.0.0.1`. Внешний вход и TLS даёт **существующий host-nginx** (он уже обслуживает несколько сайтов; второй nginx на :80/:443 не поднимаем). Наш сайт займёт `projectcrm.ru` (и `default_server`), соседние поддомены не затрагиваются.

## Технические решения

| # | Решение | Обоснование |
|---|---|---|
| D1 | **Express** (а не Fastify) | Зрелая экосистема, простая интеграция multer; для ~35 пользователей производительности с запасом. |
| D2 | **Аутентификация: JWT в httpOnly-cookie** (а не серверные сессии) | Без внешнего session-store, stateless, безопасно (httpOnly+SameSite). |
| D3 | **bcrypt (bcryptjs)** для паролей | Стандарт, без нативной сборки → надёжно ставится в Docker. |
| D4 | **PostgreSQL в Docker** (отдельный том), а не нативный серверный pg | Изоляция от старого проекта и от других сервисов; чистый бэкап/переезд через volume. |
| D5 | **Монорепо на npm workspaces** (`apps/api`, `apps/web`) | Только npm доступен; не тащим pnpm/yarn. |
| D6 | **Дев локально → деплой на сервер по rsync**, исполнение на сервере | Совпадает с прежним подходом проекта (файлы синкались с Mac), не ставим стек на Mac. |
| D7 | **Проект на сервере: `/opt/projectcontrol`** | Не пересекается со старым `/opt/app`; старый стек гасим/чистим после проверки нового. |
| D8 | **Экспорт: `exceljs` (xlsx) + серверный рендер PDF** | Кириллица в xlsx из коробки; для PDF — встроенный шрифт с кириллицей. |
| D9 | **Гант: собственный компонент (SVG/CSS)** | Полный контроль над кириллицей и адаптивом, без тяжёлых зависимостей. |
| D10 | Пороги здоровья — в конфиге (`HEALTH_*` env) | По требованию ТЗ (раздел 7). Дефолты: дедлайн «скоро» 7 дней, перегруз 🟡 >100%, 🔴 >120%. |

## Допущения

- A1. «Внутренние заметки», скрытые от заказчика, — отдельное поле/сущность с фильтрацией по роли (заказчик их не видит). В MVP — поле `internalNote` на сущностях, скрываемое в сериализации для роли `client`.
- A2. Прогноз завершения — простая оценка «опережение/отставание в днях» по доле прошедшего срока vs прогрессу (без статистических моделей).
- A3. Лимит загрузки файла 25 МБ, белый список: docx, pdf, xlsx, png, jpg/jpeg, zip.
